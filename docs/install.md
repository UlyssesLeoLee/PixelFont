# 安装与使用说明

面向的读者：拿到 `PixelFontPC98-12.ttf` 之后，想在 **Word**（以及其它 Windows 程序）里
真正用上这个像素字体的用户。

先说三句结论：

1. **你必须先卸载/覆盖旧版。** 旧版的 OS/2 元数据是错的，Windows 根本不会在中文正文里
   选中它——这正是"装了却像没装"的根因。直接覆盖安装新文件即可。
2. **字号必须取 12 的整数倍**（9 / 18 / 27 / 36 pt）。字形是 12px 设计的，
   非整数倍缩放无法还原原始像素，会出现糊边与错位。
3. **Word 的字体对话框有"中文字体"和"西文字体"两栏，两栏都要设成这个字体**，
   否则英文数字会走另一栏的字体。

---

## 1. 覆盖安装

### 1.1 先关掉 Word

安装前**完全退出所有 Word 窗口**（含后台进程）。字体被占用时覆盖会失败，
或者旧版本仍在内存里继续被使用。

### 1.2 确认你现在装的是哪一版

本机（Windows 10/11）的用户字体目录是：

```
%LOCALAPPDATA%\Microsoft\Windows\Fonts\
```

PowerShell 里查当前已安装那份的指纹：

```powershell
$p = "$env:LOCALAPPDATA\Microsoft\Windows\Fonts\PixelFontPC98-12.ttf"
if (Test-Path $p) {
  "大小: {0} 字节" -f (Get-Item $p).Length
  "sha256: " + (Get-FileHash $p -Algorithm SHA256).Hash
}
```

| 版本 | 大小 | sha256 | 状态 |
|---|---|---|---|
| 旧版（10-23） | 1,362,480 字节 | `FCC65BCBCD8A1A022007065E3444464916EDB537BB172B6F2ACDC9596DE3303B` | **元数据错误，Word 选不中** |
| 新版（本包） | **1,364,528 字节** | **`269619D5EAA0B84BC478B550893C6F5CCAAB6B0709F86AB19433AD5A8A46B2D3`** | **已修，可用** |

### 1.3 覆盖

**方式 A（推荐，最简单）**：在资源管理器里打开本包所在目录，
选中 `PixelFontPC98-12.ttf` → 右键 → **安装**（"为所有用户安装"需要管理员，
装到 `C:\Windows\Fonts`，效果一样）。

**方式 B（覆盖已有的旧版）**：把新 TTF 直接复制到

```
%LOCALAPPDATA%\Microsoft\Windows\Fonts\
```

覆盖同名文件。覆盖前**先按 §1.2 确认旧文件的大小**；覆盖后大小应变成
**1,364,528 字节**。

> 覆盖完成后建议重启一次 Word（不只是关窗口）。Windows 会缓存已加载的字体资源，
> 同名同族的新旧两版共存时，Word 可能仍然命中旧的那份。

## 2. 在 Word 里用

### 2.1 设字体（两栏都要设）

选中要改的文字 → **开始** → 字体对话框（快捷键 `Ctrl + D`）→ 字体栏输入：

```
PixelFont PC98 12
```

对话框里有**两个**下拉框：

- **中文字体**：设成 `PixelFont PC98 12`
- **西文字体**：**也**设成 `PixelFont PC98 12`

只设"中文字体"那一栏的话，英文和数字会继续用西文那栏的字体（默认可能是等线或宋体），
整段文字就会中英不是一套像素风。

### 2.2 设字号（12 的整数倍）

100% 显示缩放下：

| 字号 | 等效像素 | 说明 |
|---|---|---|
| **9 pt** | 12 px | 原始尺寸，1:1 |
| **18 pt** | 24 px | 2 倍，最常用 |
| **27 pt** | 36 px | 3 倍 |
| **36 pt** | 48 px | 4 倍 |

150% 显示缩放下用 **12 / 18 / 24 / 30 / 36 pt**。

**不要用 10.5 pt**（Word 中文默认）——那是 14 px，非整数倍，像素会被拉成不等宽的格子，
边缘发糊、笔画错位。这不是字体的缺陷，是像素字的固有约束。

### 2.3 要硬边效果

**设置 → 个性化 → 字体 → 关闭"字体平滑"**。

本机实测：在 GDI 渲染路径上，即使系统平滑开着，本字体画出来也是纯单色
（全字符集 4161 个字、12ppem 与 24ppem 两种尺寸下，抗锯齿像素合计为 **0**）。
但 Word 可能走 ClearType 等其它路径，关掉最稳。

## 3. 怎么确认装对了

按顺序过一遍：

1. **文件对不对**：
   ```powershell
   $p = "$env:LOCALAPPDATA\Microsoft\Windows\Fonts\PixelFontPC98-12.ttf"
   (Get-Item $p).Length   # 必须是 1364528
   (Get-FileHash $p -Algorithm SHA256).Hash   # 必须是 269619D5...46B2D3
   ```
2. **Word 里能看到它**：新建文档 → 字体下拉框里应出现 `PixelFont PC98 12`。
3. **中文正文真的被换掉了**：输入几个汉字，选中它们，
   看 `Ctrl + D` 对话框里"中文字体"是不是 `PixelFont PC98 12`。
   如果还显示宋体/等线，说明系统还在用别的字体处理中文——多半是旧版没被覆盖，
   或者 Word 没重启。
4. **字形没糊**：把字号设成 18 pt，边缘应当是硬边方块，不是灰边。

## 4. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 字体下拉框里找不到 | 没装成功，或 Word 没重启 | 重装 → 完全退出 Word（含任务栏后台）→ 重开 |
| 英文是像素风、中文还是宋体 | 字体对话框只设了一栏 | `Ctrl+D` 把**中文字体**和**西文字体**都设成它 |
| 字看着糊、边缘发灰 | 字号不是 12 的整数倍 | 改成 9/18/27/36 pt |
| 字看着糊、边缘发灰（字号已对） | 系统字体平滑开着 | 个性化 → 字体 → 关闭字体平滑 |
| 完全没变化，还是老样子 | 旧版仍占着同名同族 | 先卸载旧版再装新版，然后重启 Word |
| 某些字缺（显示成方框） | 该字符不在字符集内 | 本字体覆盖 4161 个码位；缺字属于字符集边界，见 `docs/word-compat.md` |
