# 安装与使用说明 —— PixelFont Multi 12

面向的读者：拿到 `PixelFontMulti-12.ttf` 之后，想在 **Word**（以及其它 Windows 程序）
里真正用上这个像素字体的人。

先说四句结论：

1. **这个字体覆盖 31,753 个码位** —— 简体中文常用汉字、日文（汉字 / 假名 / 全角）、
   **韩文谚文音节 11,172 个**、拉丁 / 希腊 / 西里尔字母与常用标点，一个字体全覆盖。
   其中**简体中文 GB2312 全部 6,763 个汉字**与**日文 JIS X 0208 全部 6,355 个汉字
   \+ 200 个符号假名**均已 100% 覆盖（这两条是构建门禁，每次构建都会核对）。
2. **它可以自由分发、可以商用** —— 生产源全部是 SIL OFL 1.1 许可（其中 4 个字形
   是本项目原创手绘，同样 OFL-1.1）。本包已随附 OFL 全文与**全部**版权声明，
   **请不要单独售卖字体本身**。
3. **字号必须取 12 的整数倍**（9 / 18 / 27 / 36 pt）。字形是 12 px 设计的，
   非整数倍缩放无法还原原始像素。
4. **Word 的字体对话框有「中文字体」和「西文字体」两栏，两栏都要设成这个字体**，
   否则英文数字会走另一栏的字体。

---

## 1. 安装

### 1.1 先关掉 Word

安装前**完全退出所有 Word 窗口**（含后台进程）。

### 1.2 覆盖安装

**方式 A（推荐）**：在资源管理器里打开本包所在目录，
选中 `PixelFontMulti-12.ttf` → 右键 → **安装**（「为所有用户安装」需要管理员）。

**方式 B**：把 TTF 复制到

```
%LOCALAPPDATA%\Microsoft\Windows\Fonts\
```

装完建议**重启一次 Word**（不只是关窗口）—— Windows 会缓存已加载的字体资源。

### 1.3 确认装对了

```powershell
$p = "$env:LOCALAPPDATA\Microsoft\Windows\Fonts\PixelFontMulti-12.ttf"
if (Test-Path $p) {
  "大小: {0} 字节" -f (Get-Item $p).Length
  "sha256: " + (Get-FileHash $p -Algorithm SHA256).Hash
}
```

应当得到：

| 项 | 期望值 |
|---|---|
| 大小 | **7,853,876 字节** |
| sha256 | **`B844D8C1F92114ACFCB2745DCFF6C1C13711BB6853B372D6BAB6B8137BF87C15`** |

> 本字体是**新家族**，与 `PixelFont PC98 12` **不冲突** —— 两者的字体名、
> PostScript 名、文件名都不同，可以同时安装、同时使用。

## 2. 在 Word 里用

### 2.1 设字体（两栏都要设）

选中文字 → **开始** → 字体对话框（`Ctrl + D`）→ 字体栏输入：

```
PixelFont Multi 12
```

- **中文字体**：设成 `PixelFont Multi 12`
- **西文字体**：**也**设成 `PixelFont Multi 12`

### 2.2 设字号（12 的整数倍）

| 字号 | 等效像素 | 说明 |
|---|---|---|
| **9 pt** | 12 px | 原始尺寸，1:1 |
| **18 pt** | 24 px | 2 倍，最常用 |
| **27 pt** | 36 px | 3 倍 |
| **36 pt** | 48 px | 4 倍 |

150% 显示缩放下用 **12 / 18 / 24 / 30 / 36 pt**。

**不要用 10.5 pt**（Word 中文默认）——那是 14 px，非整数倍。

### 2.3 要硬边效果

**设置 → 个性化 → 字体 → 关闭「字体平滑」**。

本机实测：GDI 渲染路径上全字符集 31,753 个字、12 ppem 与 24 ppem 两种尺寸下，
抗锯齿像素合计为 **0**。但 Word 可能走 ClearType 等其它路径，关掉最稳。

## 3. 覆盖范围

| 语系 / 区块 | 码位数 | 说明 |
|---|---|---|
| 汉字（U+4E00–U+9FFF） | 19,678 | 中日共享 2,078 取**中文形**，其余取日文形；Fusion 覆盖不到的 361 个简体字取 ZLabs 字形 |
| 谚文音节（U+AC00–U+D7AF） | 11,172 | 韩文 |
| 基本拉丁 / 拉丁补充 / 拉丁扩展 | 343 | 含 Latin Ext-A/B |
| 西里尔字母 | 151 | |
| 希腊字母 | 99 | |
| 假名（U+3040–U+30FF） | 189 | 平假名 / 片假名 / 浊点 |
| 全角形式（U+FF00–U+FFEF） | 85 | 含半角片假名区 |
| CJK 标点与符号（U+3000–U+303F） | 22 | |
| 通用标点（U+2000–U+206F） | 9 | |
| 其它 | 5 | `€` `→` `≠` `≤` `≥` |
| **合计** | **31,753** | |

**advance**：半角字符 6 px（663 个），CJK 与谚文 12 px（31,090 个）。
这是源字体的既有宽度 —— 强行统一会让西文或 CJK 的排版错位。

**字符集边界**：繁体中文（Big5 / 繁体常用字）**不在**本字体内。
在 `lfCharSet=BIG5` 下 GDI 不会选中本字体（这是正确行为）。
需要繁体请配合 `PixelFont PC98 12` 或其它覆盖繁体的字体使用。

**CJK 扩展 A（U+3400–U+4DBF）与 CJK 兼容表意文字（U+F900–U+FAFF）不在本字体内**
—— 这两个区块不属于 GB2312 / JIS X 0208 的范围，属于「全量」口径之外。

## 4. 怎么确认一切正常

按顺序过一遍：

1. **文件对不对** —— 按 §1.3 查大小与 sha256。
2. **Word 里能看到它** —— 新建文档 → 字体下拉框里应出现 `PixelFont Multi 12`。
3. **正文真的被换掉了** —— 输入几个汉字，选中它们，看 `Ctrl + D` 对话框里
   「中文字体」是不是 `PixelFont Multi 12`。
4. **韩文能不能选中** —— 这是本字体与 PC98 12 版最大的区别：
   本字体在 OS/2 里声明了代码页 **949（韩文）**，所以 Word 在韩文正文里
   也会选中它。PC98 12 版没有这个声明。
5. **字形没糊** —— 字号设成 18 pt，边缘应当是硬边方块。

## 5. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 字体下拉框里找不到 | 没装成功，或 Word 没重启 | 重装 → 完全退出 Word → 重开 |
| 英文是像素风、中文还是宋体 | 字体对话框只设了一栏 | `Ctrl+D` 把两栏都设成它 |
| 字看着糊、边缘发灰 | 字号不是 12 的整数倍 | 改成 9/18/27/36 pt |
| 繁体字显示成方框 | 本字体不含繁体 | 换用覆盖繁体的字体 |
| 12 pt 下笔画有轻微错位 | 渲染器在 12 px 下做网格拟合 | 见下方「关于 12 px 的精度」 |

### 关于 12 px 的精度

本字体在 **24 px 及以上**与设计位图**逐格完全一致**（实测平均偏差 0.00 px/字）。
在 **12 px**（9 pt）下，Windows 渲染器会做抗锯齿与网格拟合，
实测平均偏差 21.63 px/字 —— 这是「点阵字体 + 缩放渲染」的固有行为，不是字体缺陷。
**需要像素级精确时用 BDF 或图集**，不要指望 TTF 在 9 pt 下逐格对齐。
