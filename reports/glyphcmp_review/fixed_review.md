## 2. 存疑清单 (C)

| 码位 | 字符 | 置信度 | 理由 |
|---|---|---|---|
| `U+3099` | ゙ | low | **身份错误已修复**, 但按 brief 的字面口径仍记存疑。我方位图 = 3x2 的 `#.#` / `#.#` (两笔, **0 腔**), 与同库的 `U+309C`「半浊点゜」(3x3 空心环, 1 腔) **逐像素不同** —— lane1 报的 A 类身份错误确已修掉; 0 腔与 Unifont 的 0 一致, 也符合"浊点=两笔 / 半浊点=环"的拓扑判据。剩余疑点: 两笔是**竖画**(Fusion/Ark 12px 的竖排浊点写法), Unifont 16px 是斜撇(两撇), MS Gothic 12px 是 3 像素楔形 —— 若严格要求"撇"而非"竖", 需人工定夺。位图与 vendor 裁剪版逐字节相同, 竖画是源字体自身设计, 不是构建问题。 |
| `U+7CEF` | 糯 | low | 结构可追踪, 但比两个参考少一笔。右部「需」= 雨(一 + 冂 + **4 点齐全**, 与 Zpix 同形) + 而(一 + 冂 + 2 根内竖), **而的底部钩笔(乚)缺失** —— Zpix 末行 `..#.#....##..`、Unifont 末行 `...#...#....##..`, 我方少这一行(2 像素)。雨的 4 点、而的框与 2 根内竖全部在位, 无封闭空间填实、无笔画并带、无横画消失, 按口径**不判 B**, 记 C。 |
| `U+8845` | 衅 | low | 结构可追踪, 但比两个参考少一根内竖。左部「血」的「皿」是 2 根内竖(列 x2/x4), Zpix 与 Unifont 各有 3 根, 故血部的格数少。血的顶撇在位, 皿 的框与内部竖画都在(无整块填实、无横画消失), 按口径**不判 B**, 记 C。 |

## 4. 方法说明

1. **格位映射**取自 index JSON 的 `sheets[0].chars` (`fixed/index_a.json` + `fixed2/index.json`), 不靠图上低分辨率标签读码位。
   *`fixed/index.json` 是 20:48 的过期索引(26 字), 与当前 `fixed/glyphcmp_000.png`(21:19, 33 格)不对应, 已弃用。*
2. **列位映射实证**: 按出图工具几何 (scale=5, cell 270x114, 槽 16x16) 从 PNG 反解三列 —— 第 1 列 **65/65** 与当前构建的 stack 位图逐像素相同; 第 2 列 **64/65** 与 Zpix 参考位图逐像素相同(`U+3099` 该列画的是红色的「缺」, 属参考缺字); 第 3 列 **65/65** 与 Unifont 逐像素相同。列序「我方|Zpix|Uni」由此实证, 不是照抄表头。
3. **目视复核**: 65 格逐格过 —— 11 张 6 格对照图(微软雅黑标准 100px + 我方 8x + Zpix 5x + Unifont 5x)全部过完; 再对 7 个重点字与"到最近独立参考结构距离最大的 12 个字"做 12x 深放大对照(共 6 张深放大图), 存疑格再打 ASCII 点阵逐行核对。
4. **量具自检(两份独立实现)**: 字腔/竖段/横段 = 实现 A `bitfont.count_holes`/`count_runs`(栈式 DFS) vs 实现 B 自写并查集两遍扫描 + 独立竖横段计数。65 个字形上分歧 **0 处**; 扩展到 800 个参考字形上分歧仍为 **0 处** ⇒ 数字可用。
5. **身份碰撞全库扫描**: 65 个我方位图与 (a) 我方全字库 4140 字形 (b) Zpix 全 22228 字形 (c) Unifont 全 58909 字形, 按 (形状, 字节) 归并比对 —— 与任何**别的**码位逐像素相同者 **0 个** ⇒ 无 A 类身份错误。
6. **构建完整性**: 65 个我方位图与 `vendor/fusion-pixel-12px` 裁剪子集在 12px (`cell_ascent=11 / cell_descent=2`) 的渲染 **逐字节相同 65/65** ⇒ 路由确实生效, 裁剪/基线/切源没有引入额外偏差; 我看到的笔画级差异全部来自 Fusion 源字体的自身 12px 设计。
7. **换源前后对照**: 见 §3.1, 用 git 取换源前基准 commit 的路由名单复原旧源后逐字实测。
8. **边界说明**: 字高不同(SimHei 10 行 / MS Gothic 10–11 行 / Fusion 11 行)**不算缺陷**; 腔数只作旁证, **B 类必须目视确认三选一成立**(封闭空间被填实 / 笔画并成实心带 / 内部横画消失)才下判定; Zpix 在这 65 格中只缺 `U+3099` 一格, 该格只有 Unifont 一票。
